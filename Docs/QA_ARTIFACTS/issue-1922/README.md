All people, pay amounts, machines, accounts, identifiers, and downloads shown here
are synthetic fixtures. No production data or public statement URLs are used.

Generated by `scripts/portal-published-pay-uat.mjs` through the existing authenticated
portal harness:

```sh
node scripts/validate-authenticated-portal-uat.mjs --published-pay-only --app-url http://127.0.0.1:8108
```

The screenshots cover Home and statement details at 320px, 390px, and 1366px,
expanded saved machine/rate lines, and Simplified Chinese at 320px. The pink focus
outline on the detail heading records the keyboard navigation check.

The same run verifies saved artifact amounts against deliberately different
mutable summary values, latest period/current-version selection, profile changes,
reload and Back, private downloads, unavailable and revoked artifacts, unsupported
and legacy fallback, bounded history reads, independent timekeeping failure, and
absence of statement values or signed links in persistent browser storage.

Home keeps Add time as its primary action. Pay Stub details preserve the existing
portal design tokens, readable current/YTD columns, expandable rate detail, and
the published contractor notice. Publication does not assert that payment occurred.
